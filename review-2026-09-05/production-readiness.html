PR01 · Engine · High · Fixed by rejection

FixedValue plus terminator rejects before output

Evidence: The reproduced incomplete-output path now throws an explicit unsupported-framing error. Fixed-value raw-byte semantics are preserved; no incompatible terminator semantics are invented. Regression cases cover nonempty, empty and embedded-sentinel fixed payloads.

Impact: The writer no longer returns malformed data for this unsupported combination.

Required action: Use an ordinary terminated payload or explicit supported fixed-width framing. Supporting this combination in future requires a matching parser/writer contract.

PR04 · Engine · High · Scoped mitigation

Untrusted whole-request execution still requires an external containment contract

Evidence: Terminator scanning now uses linear-time KMP, charges the failure table before allocation, and accounts for scanned bytes and the copied result. Empty terminators produce explicit validation diagnostics. Long-prefix and overlap regressions pass. HEL limits and existing worker protections remain; synchronous SHACL/custom-codec/native work still requires externally verified process containment.

Impact: Core library calls alone do not provide hard wall-time or aggregate process-memory guarantees for arbitrary descriptions/data. A passing local suite is not a hostile-workload or deployed-isolation acceptance test.

Required action: The repeated-prefix scan gap is corrected for both terminators and synchronization markers; 4,000 deterministic differential cases pass. Complete deployed worker acceptance for compilation, arbitrary codecs and SHACL before treating untrusted whole-request execution as certified.

PR06 · Engine · Medium · Documented limitation

DLV expressiveness still exceeds executable array access

Evidence: Current IR preserves packed-cell, chunk and dynamic-stride declarations, but MultiDimensionalData.requireExecutable rejects them. This is a deliberate safe boundary, not silent corruption. Delimited writer containers and encoded struct repeat-until remain outside the writer subset.

Impact: Users can describe layouts that the generic accessor cannot execute. A production feature claim must distinguish ontology/IR representation from decoding and writing.

Required action: The versioned capability matrix now distinguishes IR representation, executable accessors, writer subsets and rejection behavior. Unsupported execution remains rejected; implementing the remaining layouts is future feature work.
