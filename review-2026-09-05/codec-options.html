Parameterized codec execution

September 10, 2026. The interpreter now supports integer level settings for zlib and raw DEFLATE: -1 selects the default; 0 through 9 select a compression level.

Pipeline clause

@prefix h: <https://hexplain.io/ns/core#> .
<urn:payload> h:hasEncodingStep (
  [ a h:EncodingStep;
    h:codec <https://www.ietf.org/rfc/rfc1950.txt>;
    h:codecParameter [ a h:CodecParameter;
      h:parameterName "level"; h:parameterValue 9 ] ]
) .

This clause belongs on a supported byte or nested-struct field with its normal datatype and extent declarations. Level controls encoding; decompression does not require it and does not prove the original encoder used that setting. Gzip options and other parameter names remain unsupported.

Implementation

  • Compilation validates parameter cardinality, integer datatype/value space, duplicate names, codec capability and option bounds.
  • Per-stage options travel with the ordered codec identifiers through parsing and writing. Shared decoded and encoded budgets still apply.
  • Directly constructed IR checks stage alignment and eligible field types. Parser/writer construction validates options even when preserved bytes would bypass encoding.
  • IR RDF exports an ordered encodingOptions list parallel to encodedWith. Each entry is an option list, with parameterName and parameterValue; empty entries preserve unparameterized stages.
  • Code generation rejects parameterized pipelines explicitly until generated runtimes carry options. It cannot silently drop them.

Verification

Full core, code-generation and HDL suites pass. The additional direct-IR regression passes. Independent JDK vectors cover zlib/raw DEFLATE levels -1, 0, 1 and 9, exact bytes, decoded values and decoded-budget rejection. Tests also cover different settings on repeated codec stages, ordered RDF export, bad values, duplicate/unknown names and unsupported codecs.

Four affected specification gates pass, including the reproducible 184-file review package and generated documentation. No vocabulary axioms or shapes changed in this pass. No fresh GDAL decode or complete parameterized-codec coverage is claimed.
