Mathematical correctness

Numerics and layout

  • Adjacent integers above 2⁵³ compare distinctly; uint64 comparisons retain exact values.
  • Signed 64-bit overflow fails instead of wrapping. Integer-only 5 / 2 = 2 and −5 / 2 = −2; 5 / 2.0 = 2.5.
  • Fractional indexes and invalid shifts fail. Unicode ordering compares code points; NaN and null behavior are explicit.
  • BMP row stride uses 4 × floor((width × bitsPerPixel + 31) / 32) for nonnegative integer inputs. Golden vectors cover widths 0–130.

Timing and semantics

  • 30000/1001 and 24000/1001 remain exact rational rates. Zero or missing denominators are invalid.
  • Negative duration/rate/counts and malformed ratios are rejected by the family validator.
  • Nominal rate is not used to infer variable-frame-rate duration.
  • The semantic integration test maps raw 100 to typed RDF integer 10, retaining raw 100 in the parse tree.

These checks establish the tested behavior. They do not exhaust every expression, parser layout, codec, RDF mapping or SHACL interaction. Exhaustive conformance, fuzzing and a second implementation remain useful assurance work.

Remaining work before a production SaaS release

  1. Durability and concurrency across processes. Replace in-memory repositories with transactions, unique constraints, migrations, backup and recovery. Current publication serialization is scoped to one application process.
  2. Production identity and execution boundaries. Add tenant-aware identity, RBAC, quotas, worker isolation/timeouts, operational monitoring and HTTPS/session configuration appropriate to the deployment.
  3. Broader UX acceptance. Perform keyboard-only and screen-reader walkthroughs in a real browser, responsive visual checks and large-file performance measurements. Files above 1 MiB need a streaming architecture.
  4. Independent correctness assurance. Run new CI on a clean remote checkout, add differential/property testing and parser fuzzing, and upstream the engine patch into a versioned release.
  5. Documentation polish. Continue first-run onboarding and static documentation/accessibility improvements beyond the numbered defects.

These limitations constrain the score and prevent a production-readiness claim. They are not silently counted as completed features.

Using the fixed application

Configure backend credentials, start both services, then sign in at the frontend’s /login. For a fresh checkout, use the pinned sibling engine revision and apply its reviewed patch exactly once. The current workspace already contains it.
