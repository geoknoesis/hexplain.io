September 10, 2026. Reviewed engine baseline b9dbf0f, focusing on recursive encoded structs, parent/root references, decoded boundaries and deferred lengths. This is a code review with new executed counterexamples, not independent ontology acceptance.

High ? fixed: emitted child values were lost

Generated nested writer functions returned no value. Although a child correctly inferred its encoded length, the parent retained the caller's original child map. Following expressions could therefore use a placeholder length instead of the emitted value. Counted results also restored the original list.

The reproducer supplies child length n=0; the child encoder infers n=14. A following parent expression reads block.n to size a 14-byte trailer. The interpreter writes the independently expected bytes. The original generated writer rejects with Payload has 14 bytes but declared size is 0. Failing regression evidence.

The fix returns the emitted child map, assigns it to the parent field and collects emitted counted elements into a private list. Caller maps and lists remain unchanged. Tests cover both a single child and a counted pair sharing the same original child object.

Other reviewed contracts

  • A four-level recursive encoded fixture matches independent JDK-compressed bytes in both writers and agrees with the interpreter's parsed tree.
  • Each recursive level sees the expected parent discriminator and original root discriminator. A depth limit below the required nesting rejects.
  • Existing tests retain decoded-stream offset checks, short decoded-frame rejection, outer trailers and cumulative work/decoded-byte limits.
  • Existing dynamic-length tests retain per-element inference, shared-length disagreement and invalid expression-length rejection. The full generated-writer suite, including PNG layout convergence, passes after the correction.

Verification

179 tests pass: 119 Kotlin backend tests and 60 compiled generated-code tests; zero failures, errors or skips. The check includes compilation against the standalone runtime. The initial 59-test run contained the deliberately reproduced failure before the fix.

Limits and release consequence

No additional defect was confirmed in the exercised scenarios. This does not prove every recursive layout or expression combination correct. Unframed encoded repeat-until arrays and unsupported dispatch/layout combinations remain outside the supported subset. Hard whole-writer isolation and a broad coverage-guided fuzz campaign were not assessed here.

The earlier staged release artifacts and their integrity manifest describe baseline b9dbf0f; they do not contain this correction. A new candidate should be staged when releasing the corrected generator. No remote CI, deployment or new production-readiness score is claimed.
