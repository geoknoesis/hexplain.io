# Contributing to the specification

Use Python 3.12 with `python -m pip install -r requirements.txt`. Run checks from the repository
root: `python tools/run_gates.py --strict`. Full git history is required by the register
extraction check. Filters such as `python tools/run_gates.py --strict numeric shapes` are
useful during development but are not complete release acceptance.

Edit shared constraint authoring where a canonical RDF module is generated. Regenerate the
affected module and documentation using its existing builder. Keep `specification/family.json`
complete when adding a vocabulary; coordinate the identical discovery contract with profiles.
Add positive and negative semantic cases, including activation, result path and numeric edges.
Regenerate changed evidence rather than weakening freshness or coverage assertions.

Public documentation links are checked by `test_site_links.py`. Run `python tools/_site_inventory.py`
after adding pages; it also links the shared print stylesheet. Namespace routes are generated by `python tools/_publication.py`; use
`python tools/_check_local_publication.py` to test the actual pinned Nginx image locally.
Refresh published profile metadata with `python tools/_sync_profile_catalog.py` after a reviewed
profile catalog update. This copies metadata, not a third set of vocabularies.

After the source and offline checks are complete, rebuild the pending review package with
`python tools/_review_candidate.py`. Do not record yourself as an independent reviewer of
your own implementation. Preserve existing attributable decisions and obtain a new review
for changed artifacts. See `specification/ontology-review/review-instructions.md`.

No live publication is implied by these local operations. See `LICENSING.md` for artifact ownership
and license declarations.
