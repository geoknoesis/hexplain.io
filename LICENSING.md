# License declarations

Existing per-file and RDF `dcterms:license` declarations remain authoritative. In particular,
ontology documents declaring CC BY 4.0 retain that declaration and attribution. Imported
samples and external specifications retain their own notices; they are not relicensed here.

No blanket license has been granted for files that lack an existing declaration. Selection
of a code license and the coverage of profile/documentation licenses is awaiting the repository
owner's decision. This file documents the current state; it does not create a new grant.
