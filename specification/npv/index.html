The Hexplain Network Protocol Vocabulary (NPV) provides standard terms for network-protocol semantics. Used with BDDO and Hexplain Core, it maps fields from packet-capture formats (PCAP, PCAPng) to concepts like source IP address, destination port, and TCP flags, enabling semantic analysis of network traffic. Prefix: npv; namespace: https://hexplain.io/ns/net#.

This document is an unofficial draft produced for the purpose of defining the Hexplain standard. It has no official standing and is not endorsed by any standards body.

Change log. Version 1.1 corrects the class name npv:UDPDDatagram to npv:UDPDatagram, adds SHACL range constraints, rdfs:comment/rdfs:isDefinedBy, and ontology metadata, declares rdfs:range and expresses domain/cardinality in SHACL (no rdfs:domain).

Introduction

Network traffic is layered: each protocol encapsulates the next. BDDO describes the physical structure of protocol data units; NPV adds the meaning of fields like "source MAC address" or "protocol number," enabling queries such as "find all TCP packets sent to port 443 from a specific IP address."

Conformance

The key words "MUST", "SHOULD", "MAY", etc. are to be interpreted as in [[RFC2119]].

Core Concepts (Classes)

npv:Packet
A single captured packet.
npv:EthernetFrame
A Layer 2 Ethernet frame.
npv:IPv4Packet, npv:IPv6Packet
Layer 3 IP packets.
npv:TCPSegment, npv:UDPDatagram
Layer 4 transport PDUs.

Semantic Properties

PropertyDescriptionRange
npv:sourceAddress, npv:destinationAddressSource/destination address (MAC, IPv4, IPv6).xsd:string
npv:sourcePort, npv:destinationPortTransport-layer ports.xsd:positiveInteger
npv:protocolNumberEncapsulated-protocol identifier (6=TCP, 17=UDP).xsd:integer
npv:etherTypeEthernet EtherType (0x0800=IPv4).xsd:hexBinary
npv:sequenceNumber, npv:acknowledgmentNumberTCP sequence / ack numbers.xsd:unsignedInt
npv:tcpFlagsTCP flags bitmask (SYN, ACK, FIN…).xsd:hexBinary

Example of Usage

An IPv4 header, using bit-level fields for the packed version/IHL byte.

@prefix bddo:     <https://hexplain.io/ns/bddo#> .
@prefix hexplain: <https://hexplain.io/ns/core#> .
@prefix npv:      <https://hexplain.io/ns/net#> .
@prefix net:      <https://hexplain.io/formats/net#> .

net:IPv4Header a bddo:Struct ;
    hexplain:mapsToClass npv:IPv4Packet ;
    bddo:endianness bddo:BigEndian ;
    bddo:bitOrder bddo:MSBFirst ;
    bddo:hasField ( net:Version net:IHL net:Protocol net:SourceAddress net:DestinationAddress ) .

net:Version a bddo:Field ; bddo:dataType bddo:uint8 ; bddo:bitLength 4 .
net:IHL     a bddo:Field ; bddo:dataType bddo:uint8 ; bddo:bitLength 4 .
net:Protocol a bddo:Field ; bddo:dataType bddo:uint8 ; hexplain:mapsToProperty npv:protocolNumber .
net:SourceAddress a bddo:Field ; bddo:dataType bddo:uint32be ; hexplain:mapsToProperty npv:sourceAddress .
net:DestinationAddress a bddo:Field ; bddo:dataType bddo:uint32be ; hexplain:mapsToProperty npv:destinationAddress .
