Specification family

Hexplain Aspect — Encoding (hx-encoding)

Orthogonal aspect for how content is coded, compressed, or encrypted (codec, bitrate; compression and encryption to follow). Controlled values (codec, compression) come from an external register bound by the profile, not from a scheme hosted in this aspect. Imported by any domain whose content is encoded.

Unofficial working specification. The namespace and version metadata below identify the vocabulary; documentation does not certify an implementation.
