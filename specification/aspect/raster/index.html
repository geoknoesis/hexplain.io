Raster aspect 1.1

Working draft · 5 September 2026

Canonical TurtleGDAL coverageModeling policy

The logical model now covers multiband grids and arrays of arbitrary rank. It complements BDDO byte structures and DLV storage layouts. These resources describe samples after parsing; adding a semantic term does not add a decoder.

Normative modeling contract

  • A RasterGrid describes a two-dimensional sample grid. Bands MAY carry separate calibration, units, no-data and validity masks. Band indexes are one-based and unique within a grid. Described bands MUST NOT exceed a declared band count; omission of some bands is allowed in a partial RDF projection.
  • SampleArray dimensions MUST be a complete, finite ordered RDF list. An empty list represents a scalar. ArrayDimension permits a zero current extent, including an empty extensible axis. A dimension resource MAY be shared between arrays and repeated within one array, as in a covariance matrix; its index is not a global property.
  • Logical array order MUST NOT be treated as a byte-stride or chunk-order declaration. Physical layout belongs to DLV. Scalar or empty semantic arrays do not imply that every processor supports zero-byte physical layouts.
  • Calibration is physical = raw × sampleScale + sampleOffset. No-data detection precedes calibration. Missing scale or offset is unspecified; an importer MAY materialize documented source defaults. Calibration values MUST be finite; NaN MAY be a no-data sentinel and requires NaN-aware detection.
  • A validity mask has zero for invalid and nonzero for valid. Alpha/transparency is a separate interpretation. Overviews cover the same domain at lower resolution; no resampling algorithm or fixed integer reduction is implied.
  • Dimension kinds are open concept schemes bound by profiles. Temporal, vertical, spectral, ensemble and other scientific axes MUST NOT be forced into fixed X/Y/Z categories.

Compatibility: existing width/height predicates remain. Their shapes now reject negative, zero, fractional or multiple values. New array and band types are additive; complete dimension lists are required only when the array model is used.

The design is informed by GDAL’s raster model and multidimensional model. Repeated axes follow the netCDF dimension model. These are conceptual correspondences, not OWL equivalence assertions.

Term reference

ArrayDimension
A reusable named axis with an extent. Its position belongs to each array's ordered dimension list, not to the shared dimension.
ArrayGroup
A logical hierarchy of groups and arrays. It does not imply filesystem directory layout.
RasterBand
One sample plane of a raster grid, with its own sample interpretation, no-data, calibration and optional mask.
RasterGrid
A two-dimensional grid with one or more co-registered bands. Higher-dimensional arrays use SampleArray; physical byte addressing remains in DLV.
SampleArray
A logical array of arbitrary rank, including rank-zero scalars and zero-length dimensions. Logical dimension order is independent of physical byte strides and chunk order.
bandCount
Total band count. A partial RDF projection may describe fewer bands, but never more than this count.
bandIndex
One-based band index within its owning grid.
coordinateArray
Array of coordinate values associated with a dimension. Its shape and alignment are asserted by the profile; coordinates need not be regularly spaced.
dimensionExtent
Current number of indexable values along this logical axis. Zero is permitted. An unlimited dimension has a finite current extent, not infinity.
dimensionKind
Axis nature from a profile-bound concept scheme; no fixed list limits scientific or non-spatial axes.
dimensionName
dimension name
dimensions
Complete ordered RDF list of ArrayDimension resources in logical indexing order. rdf:nil denotes a scalar. The list must be finite, well formed and permit repeated dimension resources at distinct positions.
hasArray
has array
hasBand
has band
hasGroup
has group
hasMask
Validity mask band: zero is invalid; nonzero is valid. This relation does not imply alpha/transparency semantics.
hasOverview
A lower-resolution representation covering the same logical domain. Does not assert a resampling algorithm or an integer reduction factor.
height
Grid extent along the vertical axis, in samples (pixels).
noDataValue
Sample value denoting absence of data in the grid.
sampleOffset
Calibration additive term, in the unit of the physical value. Independent of byte offsets and georeferencing origins.
sampleScale
Calibration multiplier: physical = raw * sampleScale + sampleOffset. Absence means unspecified, not a stored default. Apply no-data detection to raw samples first.
sampleUnit
Unit IRI for calibrated sample values; profiles may reuse established unit vocabularies.
width
Grid extent along the horizontal axis, in samples (pixels).
