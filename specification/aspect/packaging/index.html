apkg:ContainerShape — Container membership shape

IRI: https://hexplain.io/ns/aspect/packaging#ContainerShape

Label
Container membership shape
Definition
Checks resource-valued, explicitly typed entry membership. Empty containers and repeated paths on distinct entries remain legal.
Usage scope
Apply to emitted packaging metadata with entry types in the data graph; no inference or network import fetching is required. This shape does not inspect binary archive bytes.
Declared RDF type
sh:NodeShape
Domain / range
Not applicable to this node shape. Domain and range describe predicates; the types, relationships and constraints below describe this resource.

apkg:EntryShape — Entry path shape

IRI: https://hexplain.io/ns/aspect/packaging#EntryShape

Label
Entry path shape
Definition
Checks the optional single verbatim string path of an entry. A path is metadata, not an extraction destination or a globally unique identifier.
Usage scope
Applies to Entry instances and subjects of entryPath. Paths may be absent in unnamed box containers; empty paths, traversal-looking paths and duplicate paths across distinct entries are preserved for inspection. Extraction software must apply its own destination policy.
Declared RDF type
sh:NodeShape
