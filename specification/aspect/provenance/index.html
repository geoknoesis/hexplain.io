# Hexplain Aspect — Provenance & Acquisition (hx-provenance) 1.3
# Governance aspect: how data was observed/acquired. Relates to PROV and SOSA/SSN: the one
# reviewed logical alignment is aprov:Platform rdfs:subClassOf sosa:Platform (a platform hosts
# sensors); the other links are rdfs:seeAlso, because aprov:AcquisitionInfo is a record ABOUT an
# acquisition (not the prov:Activity itself) and aprov:SensorModel describes a kind of sensor
# (not the sosa:Sensor device).
# Cross-cutting (geospatial sensing, camera EXIF, scientific instruments).

# The three classes were unrelated: nothing said which platform or sensor model an acquisition
# used, so a record could only repeat their names as text (platformName, sensorType). Linked,
# not subsumed: sosa:isHostedBy relates a sensor DEVICE to its platform and sosa:madeBySensor an
# observation to a device, while an AcquisitionInfo is a record about an acquisition and a
# SensorModel a kind of sensor.
