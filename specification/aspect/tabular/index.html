atab:Table — Table

IRI: https://hexplain.io/ns/aspect/tabular#Table

Label
Table
Definition
A tabular resource: a schema of typed columns (atab:hasField) and the records laid out under it (atab:hasRecord), with an optional declared record count (atab:rowCount).
Usage scope
Map the struct that holds a table's header and records, typically a table file's root struct. A table may be described partially: it may name fewer records than its atab:rowCount, never more. Not bddo:DelimitedTable, which is the physical layout of delimited rows, not the table they encode.

# ---------- Range datatype shapes ----------
# Each XSD rdfs:range above, enforced wherever the property is used: activation is by
# subjects-of, so an untyped subject is checked too (tools/test_range_datatypes.py).
# Integer ranges accept any XSD integer-family datatype within the range's bounds.
# One copy per module, byte-identical to bddo:IntegerValueShape (the master; template in
# specification/shared-patterns/integer-value-shape.ttl.template): shapes are validated module by
# module, and a sh:node into another module's graph is silently satisfied when that module is not loaded.
atab:IntegerValueShape a sh:NodeShape ; rdfs:label "Integer value shape"@en ;
    rdfs:isDefinedBy <https://hexplain.io/ns/aspect/tabular> ;
    sh:message "An integer value is a literal of an XSD integer-family datatype (xsd:integer, xsd:positiveInteger, xsd:nonNegativeInteger, xsd:int, xsd:long, xsd:unsignedInt, xsd:unsignedLong, xsd:short, xsd:unsignedShort, xsd:byte or xsd:unsignedByte)." ;
    sh:or ( [ sh:datatype xsd:integer ] [ sh:datatype xsd:positiveInteger ] [ sh:datatype xsd:nonNegativeInteger ] [ sh:datatype xsd:int ] [ sh:datatype xsd:long ] [ sh:datatype xsd:unsignedInt ] [ sh:datatype xsd:unsignedLong ] [ sh:datatype xsd:short ] [ sh:datatype xsd:unsignedShort ] [ sh:datatype xsd:byte ] [ sh:datatype xsd:unsignedByte ] ) .
atab:RangeDatatypeShape a sh:NodeShape ; rdfs:label "Range datatype shape"@en ;
    rdfs:isDefinedBy <https://hexplain.io/ns/aspect/tabular> ;
    sh:targetSubjectsOf atab:fieldDataType ,
        atab:fieldName ,
        atab:rowCount ;
    sh:property [ sh:path atab:fieldDataType ; sh:datatype xsd:string ;
        sh:message "atab:fieldDataType takes an xsd:string literal (rdfs:range xsd:string)." ] ;
    sh:property [ sh:path atab:fieldName ; sh:datatype xsd:string ;
        sh:message "atab:fieldName takes an xsd:string literal (rdfs:range xsd:string)." ] ;
    sh:property [ sh:path atab:rowCount ; sh:node atab:IntegerValueShape ; sh:minInclusive 0 ; sh:maxInclusive 18446744073709551615 ;
        sh:message "atab:rowCount takes an integer within the xsd:unsignedLong value space (rdfs:range xsd:unsignedLong)." ] .
