Hexplain Aspect — Colour (hx-color)

Orthogonal aspect for colour interpretation (colour space; colour model and ICC profile to follow). Controlled values (colour space) come from an external register bound by the profile, not from a scheme hosted in this aspect. Shared by raster and vector styling.
