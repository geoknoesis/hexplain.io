Application-independent records, named members and collection items. Values retain their RDF datatypes; nested values are resources. This aspect describes decoded values, not physical BDDO declarations.

IRI: https://hexplain.io/ns/aspect/structure#IntegerValueShape

Label
Integer value shape
Definition
Applied through references from other shapes. An integer value is a literal of an XSD integer-family datatype (xsd:integer, xsd:positiveInteger, xsd:nonNegativeInteger, xsd:int, xsd:long, xsd:unsignedInt, xsd:unsignedLong, xsd:short, xsd:unsignedShort, xsd:byte or xsd:unsignedByte).
