Complete reference: 26 terms and shapes · All vocabularies and reading guide

The Hexplain Document & Font Vocabulary (DFV) provides standard terms for the semantic properties of document and font files. Used with BDDO and Hexplain Core, it maps fields from formats like PDF, TrueType (TTF), or PostScript to concepts such as page count, font family, and cross-reference table. Generic descriptive metadata (author, title, creation and modification dates) now reuses Dublin Core (dcterms:) directly rather than DFV-specific terms. Prefix: dfv; namespace: https://hexplain.io/ns/docfont#.

This document is an unofficial draft produced for the purpose of defining the Hexplain standard. It has no official standing and is not endorsed by any standards body.

Introduction

Document and font files carry complex structures (pages, text, vector graphics, typographic tables). BDDO describes their physical structure; DFV adds the meaning of fields like "page count" or "font family," enabling queries such as "find all documents authored by 'John Doe' that use 'Times New Roman'."

Conformance

The key words "MUST", "SHOULD", "MAY", etc. are to be interpreted as in [[RFC2119]].

Core Concepts (Classes)

dfv:Document
The document as a whole (e.g. a PDF file).
dfv:Page
A single page.
dfv:Object, dfv:Stream
An addressable object and its (often compressed) byte stream.
dfv:Trailer, dfv:CrossReferenceTable
Concluding metadata and the object index.
dfv:BoundingBox
A rectangular area (MediaBox, CropBox).
dfv:Font, dfv:FontDescriptor, dfv:FontTable, dfv:Glyph
Font definition, metrics, tables (e.g. 'cmap', 'head'), and glyphs.
