Evidence boundaries

These cases validate declarations, not decoded packed-cell arithmetic. Nested typed assets validate independently; containment does not imply security inheritance or authorization. Required-part checks need the selected profile definition in the data graph. Its absence cannot establish compliance with an unavailable profile.
