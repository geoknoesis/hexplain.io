Ontology and shape semantics

Ontology range axioms describe interpretation. They do not replace runtime validation. Optional aspect properties activate local value constraints when present; they do not require every dataset to describe every aspect. A domain profile may add completeness requirements. An absent property means no assertion, not a zero value. RDF term cardinality and numeric equality remain different checks.

The engine uses SHACL 1.0 Core and SPARQL constraints through Apache Jena. It performs no OWL or RDFS materialization. SHACL class targets and class constraints still traverse explicit subclass declarations in the supplied vocabulary. Imports are resolved from the bundled family only; validation does not fetch namespace URLs. Helper shapes from unselected modules are available for references, while their targets are inactive. Unsupported entailment requests fail. These choices follow the W3C SHACL validation contract.

Engine usage

val validator = InstanceGraphValidator.fromBundledShapes(
    "vocab/aspect/raster.ttl",
    "vocab/aspect/sampling.ttl",
    maxInputTriples = 100_000
)
val result = processAndValidateSemanticGraph(
    profile, rootStructUri, baseUri, bytes, validator
)
// Inspect result.validation.conforms and its full report.
// Nonconforming output remains available as result.graph.

The caller's graph is not mutated by validation. The source identifier is supplied by the caller; it is not a content checksum. Resource SHA-256 values identify the exact bundled Turtle bytes, not canonical RDF graph hashes. A true report may be vacuous when no instances match selected targets. Target-declaration counts are not focus-node coverage. Triple limits and interruption checks do not provide a hard SHACL query deadline; hard service guarantees require isolated execution.

Sampling and signal revision 1.1

Bit depth and component count accept positive XML Schema integer-family values, with one value per property. Zero, fractions, numeric strings and conflicting values fail. Sample interpretation is one of SignedInteger, UnsignedInteger or Float in this revision. More numeric interpretations require an explicit vocabulary revision.

Sample rate is a positive decimal or integer-family value in hertz. Decimal 0.5 means one sample instant every two seconds. Rates count sample instants, independently of channel count. Decimal values preserve finite decimal fractions exactly; they do not claim exact representation of every rational number. NaN, infinity, binary floating literals and nonpositive rates fail this contract. Convert binary approximations explicitly, preserving the original value where needed.

Executable competency and compatibility evidence

The 36-case shared corpus covers sampling, signal, time, packaging and raster values, including invalid cases and expected result paths. The same source cases run in pySHACL and Apache Jena. They supplement the existing geospatial, packaging, numeric and video suites; they are not exhaustive coverage of every vocabulary term.

Each snapshot pins its original corpus and ontology bytes. The release gate verifies hashes and replays that corpus against both archived and current shapes. New invalid-case rejection is a validation compatibility change even if term IRIs remain stable. Retain old artifacts and document migrations instead of overwriting them. Live HTTP namespace negotiation and external consumer acceptance remain deployment checks.
