Evidence ladder

  1. Term exists and has a precise contract.
  2. Representative RDF description passes SHACL; malformed variants fail.
  3. Authoring syntax compiles the intended description without semantic loss.
  4. A binary corpus parses correctly across versions, endianness and boundary cases.
  5. Payloads decode and semantic output agrees with independent expected values.
  6. Independent implementations interoperate and unsupported cases fail explicitly.

Promoting an inventory row to runtime verified requires repository evidence paths. Driver-wide or “full format” certification needs a declared subset and corpus, not one successful sample.

Priorities for the broadest binary coverage

  1. Build differential corpora for GeoTIFF/BigTIFF/COG, NITF, ENVI/EHdr and Shapefile first: shared pointer, stride, endian, bundle and geometry mechanisms exercise many families.
  2. Add scientific-container cases for HDF5/netCDF/Zarr: shared axes, empty arrays, compound values, chunk lookup, fill masks and decoding.
  3. Exercise FlatGeobuf/MVT/Arrow/Parquet schema evolution and unknown-field handling; preserve exact offsets and measured geometries.
  4. Define and prototype external access contracts for SQLite/GeoPackage and runtime schemas before claiming row-level support. Do not turn a byte ontology into an undocumented query engine.
