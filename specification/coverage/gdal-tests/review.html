Verification

565 core + 33 adapter + 223 HDL tests pass. Four separate OS worker tests verify normal exit, denied allocation, forced timeout and denied child processes. A real native workload passes under a 512 MiB commit-memory ceiling, peaking at 220.9 MiB.

The 611 GDAL 3.13.3 pixel matches remain a separate baseline. Fresh semantics use Rasterio 1.4.3 / GDAL 3.9.3 and Fiona 1.10.1 / GDAL 3.9.1. Nine TIFFs compare every pixel/mask byte, transform and CRS identifier; a CF variable additionally compares unsigned interpretation, row order and WKT; both XYZ features compare every coordinate. All eleven selected dataset/feature checks also pass independently under pinned GDAL 3.13.3. An oversized native DuckDB query is killed by the 256 MiB cgroup limit after entering native execution. Six Linux containment tests and the real native workload pass under a 512 MiB cgroup limit, disabled swap/network, read-only root and an unprivileged user.

Remaining limits

Windows and Linux offline resource limits are measured; deployed hosted load/recovery acceptance is not. The Linux launcher isolates network and filesystem access; Windows Job Objects provide resource containment only. Linux native JDBC extraction uses a dedicated executable 128 MiB tmpfs, while ordinary /tmp remains noexec. External masks, overview/SubIFD selection, HDF-EOS axes, broader CF conventions, custom CRS equivalence, LAZ and wider columnar variants remain unsupported or unverified. The existing 11 TIFF and four HDF rejections remain visible. These limits prevent a justified 9.5 score.
