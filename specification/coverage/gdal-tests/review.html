Verification

565 core + 27 adapter + 223 HDL tests pass. Four separate OS worker tests verify normal exit, denied allocation, forced timeout and denied child processes. A real native workload passes under a 512 MiB commit-memory ceiling, peaking at 220.9 MiB.

The 611 GDAL 3.13.3 pixel matches remain a separate baseline. Fresh semantics use Rasterio 1.4.3 / GDAL 3.9.3 and Fiona 1.10.1 / GDAL 3.9.1. Four TIFFs compare every pixel/mask byte, transform and CRS identifier; a CF variable additionally compares unsigned interpretation, row order and WKT; both XYZ features compare every coordinate.

Remaining limits

Windows resource limits are measured; hosted Linux/container acceptance is not. The worker does not sandbox filesystem or network access. Internal/external/alpha masks, HDF-EOS axes, broader CF conventions, custom CRS equivalence, LAZ and wider columnar variants remain unsupported or unverified. The existing 11 TIFF and four HDF rejections remain visible. These limits prevent a justified 9.5 score.
