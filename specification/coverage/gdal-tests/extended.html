GDAL evidence · Engineering review

Extended decoding, measured honestly

611 GDAL full-pixel matches, up from 570. Added 29 Zarr entry points and 12 HDF5Image files. These counts compare dimensions, datatype and every sample byte; they do not certify format-wide or geospatial semantic equivalence.

39 new test cases cover adapter values, boundaries and mathematical semantics. Companion fixtures use pinned GDAL source files where available, with SHA-256 verification and independent reference libraries.

The GDAL 3.13.3 pixel baseline is retained. Fresh semantic comparisons use pinned Rasterio 1.4.3 / GDAL 3.9.3 and Fiona 1.10.1 / GDAL 3.9.1 wheels. Nine TIFF datasets, one selected CF variable and two XYZ features match. All eleven dataset/feature checks also pass independently in pinned GDAL 3.13.3 through Docker. Semantic checks remain separate from the 611 pixel counter. Overall scores held at previous review values; this scoped pass does not establish >9.5 or production readiness. The new native-library adapters are not wired into hosted upload execution.

Signed 24-bit TIFF: explained, still a non-pass

The fixture declares SampleFormat=2 and BitsPerSample=24. Pinned GDAL GTiffOddBitsBand explicitly maps signed 17-31-bit integer widths to UInt32; its constructor contains a FIXME naming int24.tif. Hexplain preserves the signed Int32 interpretation. Existing fixture pixel bits match; separate negative-boundary tests exercise sign extension. This is an explained datatype difference, not an interoperability pass.

Pinned GDAL odd-bit band implementation. Synthetic big-endian TIFF tests verify −8,388,608, −1, 0, 1 and 8,388,607 as Int32.

Remaining acceptance work

Extend the fresh, selected-variable GDAL comparisons to HDF-EOS and broader CF conventions; add external masks, overview selection and custom CRS handling; extend columnar/point-cloud variants; investigate remaining HDF allocation and TIFF strile failures. Native adapters are optional. A Windows Job Object launcher enforces commit-memory/process limits before execution, with deadline termination; a real native workload passes. Six Linux containment tests and the real native workload also pass with memory/process limits, disabled network, read-only root and an unprivileged user. Hosted deployment/load acceptance remains separate.
