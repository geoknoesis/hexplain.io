# Hexplain Register — Protection Algorithms 1.0
# Controlled values for the hx-protection aspect: common ciphers, signature and message
# authentication algorithms, and error-correcting code families, as their specifications name
# them. A register rather than part of the aspect, so that a profile or another body can publish
# a sibling register (national ciphers, a format's own codes) without forking the aspect or
# minting into a namespace it does not own.
# Codes are NOT here: a raw wire code belongs to the format that encodes it, and is carried
# by that profile's HDL enum. Parameters a concept leaves open (key length, curve, hash, code
# length) are the profile's to state.
# Every concept states its own skos:definition: a register is read on its own.
