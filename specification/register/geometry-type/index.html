rgeo:GeometryCollection — Geometry collection

IRI: https://hexplain.io/ns/register/geometry-type#GeometryCollection

Label
Geometry collection
Definition
A geometry containing zero or more member geometries, potentially of different geometry types.
Usage scope
Use for ISO WKB type 7 or its dimensional variants. Collection membership does not itself imply a shared CRS, common ordinate layout, topology, ordering semantics or nonemptiness; the selected format profile supplies those constraints.

# Hexplain Register — Geometry Type 1.3
# Controlled values for the hx-geometry aspect: geometry-type identifiers aligned to the
# OGC Simple Features vocabulary (the sf: namespace GeoSPARQL uses for geometry types;
# GeoSPARQL itself has no geo:Point class). A concept points at its Simple Features class with
# rdfs:seeAlso, not a SKOS mapping: sf:Point is an OWL class, and skos:closeMatch relates
# concepts. Split out of the aspect so another jurisdiction
# or profile can publish a sibling register without forking the aspect or minting into a
# namespace it does not own.
# Codes are NOT here: a raw wire code belongs to the format that encodes it, and is carried
# by that profile's HDL enum.
