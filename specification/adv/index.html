The Hexplain Audio Vocabulary (ADV) provides standard terms for the semantic properties of audio data. Used with BDDO and Hexplain Core, it maps fields from formats like WAV or MP3 (ID3) to concepts such as sample rate, artist, and album. Prefix: adv; namespace: https://hexplain.io/ns/audio#.

This document is an unofficial draft produced for the purpose of defining the Hexplain standard. It has no official standing and is not endorsed by any standards body.

Change log. Version 1.1 adds SHACL range constraints, rdfs:comment/rdfs:isDefinedBy, ontology metadata, and alignments to the W3C Ontology for Media Resources and Dublin Core; declares rdfs:range and expresses domain/cardinality in SHACL (no rdfs:domain). Note: this vocabulary was previously published at the axv/ path in error; its canonical location is now adv/.

Introduction

Audio files carry both technical data (the encoded stream) and descriptive metadata (tags). BDDO describes the physical structure; ADV adds the meaning of fields like "sample rate" or "artist," enabling queries such as "find all audio by 'The Beatles' at 44100 Hz."

Conformance

The key words "MUST", "SHOULD", "MAY", etc. are to be interpreted as in [[RFC2119]].

Core Concepts (Classes)

adv:AudioContainer
The audio file as a whole (WAV, MP3…).
adv:AudioStream
The encoded audio sample data.
adv:MetadataTag
A descriptive tag block (ID3, Vorbis comment).

Semantic Properties

PropertyDescriptionRange
adv:sampleRateSamples per second (Hz).xsd:positiveInteger
adv:audioChannelsChannel count (1 mono, 2 stereo).xsd:positiveInteger
adv:bitDepthBits per sample.xsd:positiveInteger
adv:durationDuration in seconds.xsd:decimal
adv:bitrateAverage bitrate (bits/s).xsd:positiveInteger
adv:codecIdentifierCodec name ("PCM", "MP3", "FLAC").xsd:string
adv:artist, adv:album, adv:trackTitle, adv:genreDescriptive tags.xsd:string
adv:trackNumberTrack number.xsd:positiveInteger

Layout Axes

ADV adds audio-specific axes to DLV: adv:axisSample (often corresponds to time; see dlv:axisTime) and adv:axisChannel (for interleaved channels; see dlv:axisBand).

Example of Usage

@prefix bddo:     <https://hexplain.io/ns/bddo#> .
@prefix hexplain: <https://hexplain.io/ns/core#> .
@prefix adv:      <https://hexplain.io/ns/audio#> .
@prefix wav:      <https://hexplain.io/formats/wav#> .

wav:FormatChunk a bddo:Struct ;
    hexplain:mapsToClass adv:AudioStream ;
    bddo:endianness bddo:LittleEndian ;
    bddo:hasField ( wav:SampleRate wav:Channels wav:BitsPerSample ) .

wav:SampleRate a bddo:Field ; bddo:dataType bddo:uint32 ; hexplain:mapsToProperty adv:sampleRate .
wav:Channels a bddo:Field ; bddo:dataType bddo:uint16 ; hexplain:mapsToProperty adv:audioChannels .
wav:BitsPerSample a bddo:Field ; bddo:dataType bddo:uint16 ; hexplain:mapsToProperty adv:bitDepth .
